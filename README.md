# AttendFlow-CRM

Vite + React + Tailwind project scaffold with React Router, Redux Toolkit, Firebase Auth, Lucide icons, and React Hot Toast.

Install:

```bash
pnpm install
# or
npm install
# or
yarn
```

Run dev server:

```bash
npm run dev
```

Set Firebase env variables in `.env` (use `VITE_` prefix) or replace placeholders in `src/firebase/firebase.js`.
